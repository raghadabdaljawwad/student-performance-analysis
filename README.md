# Student Performance Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on analyzing student performance through Exploratory Data Analysis (EDA). It aims to explore student data, identify patterns, and understand the factors that may be associated with academic performance.

The project was developed as part of the Introduction to Data Science course at An-Najah National University.

## 🎯 Project Objectives

- Explore and understand the student performance dataset.
- Perform data inspection and analysis.
- Identify patterns and relationships within the data.
- Use statistical and visual techniques to understand student performance.
- Present insights through data visualizations.

## 🛠️ Tools & Technologies

- **Python** – Programming language.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical computations.
- **Matplotlib** – Data visualization.
- **Jupyter Notebook** – Interactive data analysis.

## 📊 Project Workflow

1. Importing Libraries and Setting Global Configurations.
2. Loading and Exploring the Dataset.
3. Data Inspection and Understanding.
4. Data Cleaning and Preprocessing.
5. Exploratory Data Analysis.
6. Statistical Analysis and Data Visualization.
7. Interpreting the Results.
